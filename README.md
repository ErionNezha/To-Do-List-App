# Detyrat e Mia

Organizo ditën tënde — detyra me prioritete dhe projekte, të ruajtura lokalisht.

## ✨ Veçoritë

- ➕ Shto detyra me Enter (emër + prioritet + projekt tekst i lirë)
- 🔴🟡🟢 Prioritete me badge me ngjyra (E lartë / Mesatare / E ulët)
- 📁 Projekte me chips filtri (krijohen automatikisht nga detyrat)
- 🔎 Filtra: Të gjitha / Aktive / Të kryera
- ✅ Checkbox custom — klik = kryer (me strikethrough)
- 👈 Swipe majtas në touch (>80px) = fshi me animacion
- 🧹 "Pastro të kryerat" + numërues "X aktive"
- 💾 Ruajtje lokale (localStorage) — 100% demo, pa server
